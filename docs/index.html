产品介绍

详情页的图片，
不该靠一张张另存

图提取把「找图、筛图、转格式、改名」这几件重复劳动，压缩成一次点击。

做电商的人都遇到过：商品主图、详情长图、SKU 缩略图散落在页面各处。想整理一套素材，只能右键、另存、改名，重复几十次。

图提取（ImageGrab）是一款运行在 Chrome 里的轻量扩展。打开商品详情页，点击右下角的「获取图片」，它会自动扫描页面中真实加载的商品图，并在新标签页里集中展示。

勾选需要的图片，一键转成 PNG 批量下载，文件名自动编号为 商品图_001.png、商品图_002.png……下载即可直接交给设计或运营使用。

  • 图片分散

    主图、详情长图、SKU 图分处不同模块，长图还要先点开才能保存。

  • 无法批量保存

    浏览器一次只能右键保存一张，几十张图片全靠机械重复。

  • 格式不统一

    jpg、webp、avif 混在一起，后期还要逐张转换格式、重命名。

核心功能

从提取到下载，一条流程做完

六个功能覆盖采集、筛选、预览、勾选、转码、保存的完整链路。

  • 一键提取

    自动扫描页面所有商品图，匀速滚动触发懒加载，扫描结束后回到原滚动位置。

  • 智能过滤

    自动排除图标、logo、头像、占位图，以及任一边小于 100px 的小图。

  • 集中预览

    新标签页网格展示全部图片，缩略图与原图自动合并去重，不重复不入库。

  • 自由勾选

    支持全选、反选、清空与 Shift 区间选择，几百张图片也能快速筛出要用的。

  • 统一 PNG

    在扩展页内抓取原图并用 canvas 转为 PNG，跨域图片同样适用，不吃 CORS。

  • 批量下载

    一键保存到浏览器下载目录，文件名按 商品图_001.png 自动编号。

单页最多处理 300 张图片，超出时按面积从大到小保留；少数强防盗链 CDN 无法转码时会自动回退为原格式下载。

安装步骤

四步装好，大约一分钟

插件以 zip 压缩包分发，通过 Chrome 的「加载已解压的扩展程序」安装。

  1. 1

    下载并解压

    下载插件压缩包，解压到本地任意文件夹。请记住路径，第 4 步需要选择这个文件夹。

  2. 2

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions，按回车进入。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关，页面顶部会出现三个新按钮。

  4. 4

    加载扩展程序

    点击「加载已解压的扩展程序」，选择解压后的文件夹（包含 manifest.json 的那一层）。

安装完成后，扩展管理页里会显示「电商图片提取下载器」。打开淘宝、京东或拼多多商品详情页，右下角出现紫色的「获取图片」按钮即可使用。
